## 3. 技术选型（Level 4 联网核查）

| 决策 | 选择 | 核查来源与取舍 |
| --- | --- | --- |
| HTTP/SOAP 服务框架 | Python 3.12 + FastAPI 0.162.0 + uvicorn 0.54.0（PyPI 核对最新版） | 对比 WireMock/MockServer/Mountebank 等通用 mock 工具：均缺乏 MQTT 与 SOAP/CDATA-JSON 的有状态行为，且 MOM/IoT 需要按时间窗口、推送配置等运行状态作出响应，故自研轻量服务；CV 定义的 422 `detail[]` 格式即 FastAPI/Pydantic 默认格式 |
| MQTT Broker | Eclipse Mosquitto 2.1.2（本机已有镜像）+ `password_file` + `acl_file`，`allow_anonymous false`，`accept_protocol_versions 3,4,5` | mosquitto.org 手册核对 2.x 默认拒绝匿名、ACL 语法；与 EMQX 比较后选择单节点轻量方案（无需集群） |
| MQTT 客户端 | paho-mqtt 2.1.0，`CallbackAPIVersion.VERSION2`，`MQTTv311`，QoS0/Retain false | eclipse.dev paho 文档核对构造参数与 publish 返回值 |
| SOAP 行为 | SOAP 1.1：`text/xml`，Fault → HTTP 500，`faultcode` 限定名（Client/VersionMismatch） | W3C SOAP 1.1 Note §6.2 |
| 公网验证 | check-host.net `check-tcp`/`check-http` API | 官方 API 文档核对参数与结果格式 |
