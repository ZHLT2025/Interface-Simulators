# 接口符合性与运行验证报告（第一阶段）

版本：V1.0 ｜ 日期：2026-10-26 ｜ 执行主机：185.189.48.12 ｜ 证据目录：`docs/evidence/`

## 1. 验证方法

1. **符合性测试**（`tests/conformance/`，pytest 37 项）：在一次性容器中以**公网 IP** `185.189.48.12` 为目标发起真实 HTTP/MQTT 调用。每项断言的预期值直接转录自接口定义说明书的字段表与请求/响应示例（例如 MOM 1.4.2、IoT 20.4.2、ESB 1.4.2/2.4.2/2.4.3、CV 24.4.1/24.4.3），不从模拟器输出反向生成。
2. **公网可达性**：使用第三方探测服务 check-host.net 从海外多个节点对 5 个端口做 TCP 连接、对 4 个 HTTP 健康端点做 HTTP GET。
3. **交互证据**：每个模拟器的 `/_sim/requests` 记录（Authorization 已脱敏）抽样保存；MQTT 用 `mosquitto_sub` 抓取真实消息。
4. **边界保持**：原件 ZIP 的 SHA-256 在任务结束时复核；四个现有业务系统未做任何修改。

| 场景 | 预期（来源） | 实测 |

## 6. 结论

四类模拟器的 11 项接口/消息契约已在公网部署实例上以真实调用证明符合接口定义原件的已确定行为；暂定行为均已标注并可配置。本报告不构成 YQYD S01 适配通过或多系统集成测试通过的结论。
