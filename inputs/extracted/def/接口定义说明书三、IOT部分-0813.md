| 项目 | 填写内容 |

### 23.4. Payload 字段

> Payload 根节点是数组，不存在名为 `data` 的包裹字段。字段路径使用 `$[]` 表示根数组元素。

| 字段路径 | 中文含义 | 类型 | 是否必有 | 示例 | 单位、格式或枚举 |
| --- | --- | --- | --- | --- | --- |
| `$` | 消息根数组 | Array | 是 | — | 每条消息只包含本采样时刻发生变化的点位 |
| `$[].deviceCode` | 设备编码 | String | 是 | `cqx11` | 当前已知：`cqx11`、`cqx12`、`dxdm`、`ckdm1`、`ckdm2`、`ckdm3` |
| `$[].identifiers` | 参数编码 | String | 是 | `HJ1.S0.CurrentPS1` | 字段名按现有消息保留复数形式 |
| `$[].serverTime` | 服务器时间 | String | 是 | `2026-07-01 11:48:59` | 格式与时区待确认 |
| `$[].sourceTime` | 设备端时间 | String | 是 | `2026-07-01 11:46:06` | 格式与时区待确认 |
| `$[].value` | 参数值 | String | 是 | `203.99786` | 当前按字符串传输，实际业务类型由参数清单确定 |

### 23.6. 首次发布、订阅与成功判定

> 当前仅有生产 Broker；执行发布测试前必须取得发布方授权，且不得使用真实生产 Topic 做未审批写入。发布测试必须使用具备 Publish 权限的测试账号；订阅测试使用具备 Subscribe 权限的账号。

#### 23.6.1 前置条件

1. 已打通客户端至 Broker `10.220.30.147:1883` 的网络访问。
2. 已取得有效用户名、密码以及目标 Topic 的发布或订阅权限。
3. 发布端与订阅端使用不同且唯一的 Client ID，并约定首次验证 Topic `pushToFactory/BJZHLT/device/cqx11`。
4. 将本接口完整消息示例中的 JSON Payload 保存为 UTF-8 编码的 `payload.json`。

#### 23.6.2 订阅示例（MQTT/TCP）

```bash
mosquitto_sub -h 10.220.30.147 -p 1883 -V mqttv311 \
  -i if-23-sub-test -u '<username>' -P '<password>' \
  -t 'pushToFactory/BJZHLT/device/cqx11' -q 0 -v
```

#### 23.6.3 发布示例（MQTT/TCP）

```bash
mosquitto_pub -h 10.220.30.147 -p 1883 -V mqttv311 \
  -i if-23-pub-test -u '<username>' -P '<password>' \
  -t 'pushToFactory/BJZHLT/device/cqx11' -q 0 -f payload.json
```

#### 23.6.4 首次验证成功判定

同时满足以下条件，视为首次发布和订阅链路验证成功：

1. 发布端、订阅端的 MQTT CONNECT 均被 Broker 接受。
2. 订阅端收到成功 SUBACK；不是订阅失败码。
3. 发布端发送消息时客户端未报告错误。QoS 0 没有 PUBACK，最终以订阅端实际收到消息为准。
4. 订阅端收到 Topic `pushToFactory/BJZHLT/device/cqx11`，Payload 可按 UTF-8 解析为合法 JSON，字段与本接口定义一致。
5. 消息能够完成至少一次预期的动画、状态、标签、面板或事件更新。

#### 23.6.5 首次验证异常定位

| 现象 | 首次检查项 |
| --- | --- |
| 无法建立连接 | 核对 Broker、端口、传输方式、网络和防火墙；WebSocket 还需核对握手路径 |
| MQTT 连接被拒绝 | 核对 MQTT 3.1.1、用户名、密码、Client ID 唯一性和账号状态 |
| 订阅失败 | 核对 Topic 拼写、QoS 和 Subscribe ACL |
| 发布无报错但订阅端无消息 | 核对 Publish ACL、双方 Topic 是否完全一致；注意 `Retain=false` 不补发历史消息 |
| 收到消息但 JSON 或业务解析失败 | 保留原始 Topic/Payload，核对 UTF-8、JSON 语法、字段类型、单位和枚举 |
